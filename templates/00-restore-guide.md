# Как восстановить Claude на новом аккаунте

Бэкап собран {{DATE}}. Память обновляется автоматически каждую пятницу.

## Что лежит в папке

| Файл | Что это |
|---|---|
| 00 — этот документ | Порядок восстановления |
| 01 — Память Claude (дата) | Вся память. Берите самый свежий |
| 02 — Claude Code | Что бэкапить из Claude Code и как восстановить |
| 03 — Промпт для Claude Code | Заливает все проекты на GitHub с CONTEXT.md |
| Реестр проектов | Все проекты: GitHub, папка, карточка, что докинуть |
| backup-claude-code.sh / .ps1 | Скрипты бэкапа Claude Code |
| conversations-000.zip, projects-000.zip | Экспорт чатов и проектов (кладёте сами) |
| Projects/ | Папка и карточка CONTEXT на каждый проект |

## Регулярно, пока аккаунт жив

1. Раз в месяц: Settings → Privacy → Export data. Ссылки из манифеста одноразовые — скачивайте по одной и кладите архивы сюда.
2. Раз в неделю: промпт 03 в Claude Code — запушит свежий код и обновит CONTEXT.md.
3. Один раз: поставить cron или планировщик для скрипта бэкапа Claude Code (команды в 02).

## Восстановление

1. Новый аккаунт → подключить Google Drive → включить память (Settings → «Generate memory from chats»).
2. Установить скилл claude-autobackup и в новом чате написать: «Восстанови всё из папки Claude Backup». Без скилла: «Импортируй в память самый свежий документ 01 из папки Claude Backup на моём Drive».
3. Пересоздать Projects с теми же названиями, загрузить файлы из `Projects/<проект>/`.
4. Claude Code: распаковать архивы по документу 02, выполнить `/login`.
5. Заново поставить еженедельную задачу бэкапа (она умерла вместе со старым аккаунтом).
6. История чатов обратно не импортируется — `conversations.json` из архива используйте как справочник.

## Важно

Документ 01 содержит личные данные. Не открывайте доступ к папке по ссылке.
