# Claude Autobackup

Цель: если аккаунт Claude заблокируют, пользователь за 15 минут поднимает всё на новом аккаунте — память, проекты, контекст, код. Всё ценное лежит вне аккаунта: в Google Drive и на GitHub.

Определи режим по запросу:

- **Первичная настройка** — «сделай бэкап», «настрой автобэкап». → раздел A
- **Еженедельное обновление** — запуск из Scheduled или «обнови бэкап». → раздел B
- **Восстановление** — «я на новом аккаунте, верни всё». → раздел C

## Что нужно

- Коннектор **Google Drive** (обязательно). Если его нет — найди в каталоге коннекторов и предложи подключить.
- **Claude in Chrome** (желательно): проверка GitHub, запуск экспорта, создание задачи в Scheduled. Без него эти шаги пользователь делает сам по инструкции.
- **Claude Code** у пользователя на компьютере — для пуша кода на GitHub. Чат до локального диска не дотягивается.

## Жёсткие правила

1. **Не вводи пароли, коды подтверждения, токены.** GitHub при смене видимости репо может попросить sudo-подтверждение по почте — это делает только пользователь. Остановись и скажи, какую кнопку нажать.
2. **Ничего не удаляй и не расшаривай.** Папка бэкапа приватная. Старые версии документов не трогай.
3. **Только факты.** В карточки и документы — только то, что есть в памяти, коде или репо. Чего не знаешь — пиши «уточнить», не выдумывай.
4. **Секреты не в бэкап.** Скрипты исключают `.credentials.json`; промпт для GitHub требует проверить код на ключи перед коммитом.
5. **Предупреди про личные данные.** Документ памяти может содержать адреса, данные о семье и финансах — напомни не открывать доступ к папке по ссылке.
6. **Публичные репо — флаг.** Если при проверке GitHub находится публичный репозиторий с рабочим/клиентским кодом — скажи пользователю и предложи закрыть (только с его «да»).

## A. Первичная настройка

Делай по порядку, после каждого шага коротко отчитывайся.

### A1. Собрать память
Прочитай всю память: `memory_list` (включая префиксы `/projects/` — память Projects) и `memory_read` всех файлов одним вызовом. Не пересказывай — переноси дословно.

### A2. Структура на Drive
Создай папку `Claude Backup` в корне Drive. Внутри:

```
Claude Backup/
├── 00 — Как восстановить всё на новом аккаунте     (Google Doc)
├── 01 — Память Claude (ГГГГ-ММ-ДД)                  (Google Doc)
├── 02 — Claude Code: бэкап и восстановление         (Google Doc)
├── 03 — Промпт для Claude Code: залить всё на GitHub (Google Doc)
├── Реестр проектов                                  (Google Sheet)
├── backup-claude-code.sh                            (сырой файл!)
├── backup-claude-code.ps1                           (сырой файл!)
├── Projects/<проект>/CONTEXT — <проект>             (Google Doc на каждый)
└── Artifacts/
```

Шаблоны: `templates/00-restore-guide.md`, `templates/02-claude-code.md`, `templates/context-card.md`, `templates/registry.csv`. Промпт для 03 — `prompts/github-push.md`. Формат 01 — `templates/01-memory-export.md`.

Как создавать файлы:
- Документы: `create_file` с `contentMimeType: text/markdown` — Drive сам сконвертирует в Google Doc.
- Реестр: `text/csv` → станет Google Sheet.
- **Скрипты `.sh`/`.ps1` — только с `disableConversionToGoogleType: true`.** Google Docs ломает переносы строк в блоках кода, и скрипт перестаёт работать. Подробнее — `references/gotchas.md`.
- Папки: `contentMimeType: application/vnd.google-apps.folder`. Запоминай id — понадобятся для ссылок в реестре и для задачи в Scheduled.

### A3. Карточки проектов
Проект = любой файл `/areas/` из памяти, проекты из `/topics/recent-work.md` с кодом или документами, каждый Claude Project, каждый найденный репозиторий GitHub. На каждый — подпапка в `Projects/` и карточка по шаблону. В карточке обязательно раздел «Что докинуть в эту папку» — это то, что живёт только в чатах (спеки, зипы скаффолдов) и пропадёт при бане.

### A4. Сверка с GitHub (если есть браузер)
Открой `github.com/<user>?tab=repositories` и страницы организаций пользователя (`get_page_text`). Сопоставь репо с проектами, впиши ссылки в реестр и карточки. Репо, которых нет в памяти, тоже внеси — это проекты, о которых ты не знал. Отметь в реестре проекты с кодом без репо: их зальёт промпт 03.

### A5. Экспорт чатов
Settings → Privacy → Export data → All → Export (через браузер или попроси пользователя). Письмо приходит за минуты. **Внимательно**: письмо даёт манифест (JSON) со ссылками на несколько архивов (`conversations`, `projects`, `memories`, …), каждая ссылка **одноразовая** и живёт 24 часа. Chrome молча блокирует вторую и следующие автозагрузки с одного сайта. Поэтому:
- качай по одной ссылке, после каждой проси пользователя подтвердить, что файл появился в «Загрузках»;
- при первом запросе Chrome «Разрешить скачивание нескольких файлов» пользователь жмёт «Разрешить»;
- главное — `conversations-000.zip` (все чаты) и `projects-000.zip`. `memories` уже есть в документе 01.
- Залить архивы с диска в Drive ты не можешь — пользователь перетаскивает их в папку (или в «Google Drive» в боковой панели Finder, если стоит Drive for Desktop).

### A6. Еженедельная задача
claude.ai → Scheduled → New task → Set up manually. Имя «Бэкап Claude — пятница», Weekly, пятница, 18:00. Инструкции — из `prompts/scheduled-weekly.md`, подставь id папок. Сохрани. Если браузера нет — дай пользователю текст и шаги.

### A7. Итог пользователю
Коротко: ссылка на папку; что сделано; что осталось сделать руками (обычно: перетащить архивы экспорта, запустить промпт 03 в Claude Code, поставить cron для скрипта). Не больше пяти пунктов.

## B. Еженедельное обновление

1. Прочитай всю память.
2. Создай новый документ `01 — Память Claude (ГГГГ-ММ-ДД)` в `Claude Backup`. Старые не трогай.
3. Сравни проекты памяти с «Реестром проектов». Для новых — подпапка и карточка в `Projects/`.
4. Ничего не удаляй, не расшаривай, работай только внутри папки.
5. Отчёт: ссылка на новый 01, какие проекты добавлены, напоминание — промпт 03 в Claude Code, раз в месяц Export data.

## C. Восстановление на новом аккаунте

1. Попроси подключить Google Drive и включить память (Settings → «Generate memory from chats»).
2. Найди папку `Claude Backup`, прочитай `00` и самый свежий `01`.
3. Импортируй `01` в память — используй скилл `import-memory`, если он есть; иначе сохраняй файлы по путям из заголовков разделов, с алиасами. Раздел «Память Projects» — импортировать изнутри соответствующих проектов после их пересоздания.
4. Помоги пересоздать Projects: названия из реестра, файлы из `Projects/<проект>/`.
5. Claude Code: распаковать архивы по `02`, `/login` новым аккаунтом, переподключить MCP.
6. Поставь заново еженедельную задачу (A6) — она умерла вместе со старым аккаунтом.
7. История чатов обратно не импортируется. `conversations.json` из архива — справочник: найти разговор и вставить кусок в новый чат.

## Работа с Google Docs/Sheets через браузер

Править уже созданные документы через UI хрупко. Перед этим прочитай `references/gotchas.md` — там описаны реальные грабли (Найти-и-заменить, кириллица в Sheets, автодополнение) и как их обходить. Главное правило: **после каждого открытия диалога или меню — скриншот, и только потом печатать**. Если диалог не открылся, напечатанный текст уйдёт прямо в документ.
