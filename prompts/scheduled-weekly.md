# Промпт для еженедельной задачи (Scheduled)

Настройки задачи: имя «Бэкап Claude — пятница», Weekly, Friday, 18:00, Permissions — Automatically approve. Подставь id папок из своей структуры.

---

Еженедельный бэкап Claude на случай потери аккаунта. Используй скилл claude-autobackup, режим «Еженедельное обновление». Язык: русский.

1. Прочитай всю мою память целиком, включая память проектов (Projects).
2. В Google Drive в папке «Claude Backup» (id {{BACKUP_FOLDER_ID}}) создай новый Google Doc «01 — Память Claude (ГГГГ-ММ-ДД)» с сегодняшней датой: сверху инструкция для импорта в память на новом аккаунте, дальше все файлы памяти по разделам с путями, алиасами и всеми фактами, память Projects отдельным разделом. Старые версии не трогай.
3. Сравни проекты из памяти с «Реестром проектов» в той же папке. Для каждого нового проекта создай подпапку в Projects (id {{PROJECTS_FOLDER_ID}}) с карточкой «CONTEXT — имя» по образцу существующих. Только факты из памяти.
4. Ничего не удаляй, не расшаривай и никому не отправляй. Работай только внутри папки Claude Backup.
5. В конце коротко: ссылка на новый документ 01, какие проекты добавлены, напоминание запустить промпт 03 в Claude Code, а раз в месяц сделать Export data.
