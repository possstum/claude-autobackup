# Промпт для Claude Code: залить все проекты на GitHub

Запускать в Claude Code на своём компьютере, в папке, где лежат все проекты.

Подготовка (один раз): установить GitHub CLI и выполнить `gh auth login`. Проекты, которые существуют только как зипы из чатов, сначала скачать и распаковать в ту же папку.

Запуск: `cd ~/projects && claude`, затем вставить текст ниже.

---

Задача: забэкапить на GitHub все проекты из текущей папки и в каждом оставить CONTEXT.md, по которому другой разработчик или AI продолжит работу без истории чатов.

Для каждого подкаталога-проекта:
1. Нет git — git init, ветка main.
2. Проверь .gitignore: node_modules, .venv, dist, build, кэши, .env и .env.*, ключи, сертификаты. Создай или дополни.
3. Перед коммитом проверь отслеживаемые файлы на секреты (токены, API-ключи, пароли, строки подключения). Нашёл — в этом проекте ничего не коммить, покажи список и спроси. Если секрет уже в истории git — сообщи отдельно.
4. Нет remote — `gh repo create <GITHUB_USER_OR_ORG>/ИМЯ --private --source=. --remote=origin` (имя из папки, латиница, kebab-case). Существующий remote не трогай. Если репо уже существует и публичный — сообщи мне.
5. Создай или обнови CONTEXT.md: что это и для кого, стек, архитектура, ключевые решения и почему, статус и следующие шаги, как запустить, переменные окружения (только имена), внешние сервисы, ссылки на документы. Источники: код, README, CLAUDE.md, история коммитов. Не знаешь — пиши «уточнить».
6. Коммит «backup: CONTEXT.md и .gitignore», push всех веток и тегов.

В конце таблица: проект | ссылка на репо | статус (запушен / пропущен и почему).

---

После выполнения: скопировать таблицу в чат с Claude — он впишет ссылки в «Реестр проектов» и карточки.
