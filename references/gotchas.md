# Грабли, на которые уже наступили

Собрано на реальной настройке бэкапа. Читай перед работой с Drive/Docs/Sheets/экспортом.

## Google Drive

- **Markdown → Google Doc ломает код.** Блоки кода превращаются в абзацы с пустыми строками между ними, многострочные bash-команды с `\` перестают работать. Скрипты всегда загружай сырыми файлами (`disableConversionToGoogleType: true`), а в документах давай только однострочные команды.
- **Правка своих же документов.** Через Drive-коннектор существующий Google Doc не отредактировать — только создать новый. Для еженедельного 01 это нормально (новый файл с датой). Для точечных правок нужен коннектор Google Docs или браузер.
- **Проверка результата.** После любой правки через браузер выгрузи документ через `download_file_content` (`text/plain`) и убедись, что текст правильный. Скриншот не показывает весь документ.

## Google Docs через браузер

- Сочетание `cmd+shift+h` (Найти и заменить) часто не срабатывает. Надёжно: меню «Правка» → «Найти и заменить».
- Первый клик по «Правка» сразу после загрузки документа иногда только фокусирует страницу. **Всегда делай скриншот после клика по меню и после открытия диалога.** Если диалог не открылся, а ты начал печатать, текст вставится прямо в документ (в реальном прогоне так испортились заголовки пяти карточек).
- Позиция диалога меняется вместе с размером окна. Не переиспользуй координаты с прошлого документа без свежего скриншота.
- Чинить испорченное: Найти = вставленный мусор, Заменить = пусто или исходный текст. Или Файл → История версий.

## Google Sheets через браузер

- Ячейку выбирай через поле имени слева над таблицей: кликнуть, набрать `D4`, Enter. Его координаты тоже зависят от размера окна — сверяйся со скриншотом.
- **Кириллица теряет первое слово**, если печатать сразу в выделенную ячейку. Сначала Enter (режим редактирования), потом текст.
- Перезапись непустой ячейки: Delete → Enter → текст → Enter.
- **Автодополнение**: если в столбце уже есть «НЕТ РЕПО», то при наборе «нет кода» Sheets подставит «НЕТ РЕПО». Начинай значение с другой буквы или проверяй результат.
- Tab внутри одного `type` не переходит в соседнюю ячейку — всё ляжет в одну. Заполняй по ячейке.

## Экспорт данных Claude

- Письмо «Your data is ready» ведёт на загрузку **манифеста** (`manifest-<id>.json`), а не архива. В манифесте несколько ссылок: `conversations`, `projects`, `memories`, `light_metadata`, `design_chats`, `frames`.
- Каждая ссылка **одноразовая**: открыл — потратил, даже если файл не скачался.
- Chrome блокирует вторую и последующие автозагрузки с claude.ai молча (или с маленькой иконкой в адресной строке). В реальном прогоне пять из шести ссылок сгорели именно так.
- Правильно: одна ссылка → пользователь подтверждает, что файл в «Загрузках» → следующая. Сгорело — запускай новый экспорт.
- Залить файл с диска пользователя в Drive Claude не может (`file_upload` работает только с файлами, расшаренными в сессию). Пользователь перетаскивает сам.

## GitHub

- Публичный API без токена быстро упирается в rate limit — смотри репозитории через браузер (`get_page_text` на странице репозиториев), а не через curl.
- Не забывай организации пользователя: рабочие репо часто лежат там, иногда публично.
- Смена видимости репо требует sudo-подтверждения кодом на почту. Это вход в аккаунт — делает только пользователь.
- Загрузка файлов через веб-интерфейс GitHub: после вставки файлов подожди 5 секунд и сделай скриншот, прежде чем жать «Commit changes» — иначе коммит молча не создаётся.

## Scheduled tasks

- Раздел: `claude.ai/scheduled-task` → New task → Set up manually.
- Время вводится в поле рядом с частотой: тройной клик, набрать `18:00`, Tab.
- Задача живёт в аккаунте и умрёт вместе с ним — после восстановления её нужно создать заново.
