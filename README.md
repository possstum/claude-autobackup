# claude-autobackup

Скилл для Claude: полный бэкап аккаунта на случай блокировки и восстановление на новом аккаунте за 15 минут.

## Что делает

Одной фразой «сделай бэкап Claude» собирает в Google Drive папку **Claude Backup**:

- **Память** — вся, дословно, в формате для импорта на новый аккаунт. Обновляется каждую пятницу.
- **Карточки проектов** — по одной на проект: что это, ключевые решения, ссылка на GitHub, что ещё докинуть.
- **Реестр проектов** — таблица: проект → репозиторий → папка → карточка.
- **Сверка с GitHub** — находит репо, о которых Claude не знал, и подсвечивает публичные.
- **Экспорт чатов** — запускает Export data и правильно скачивает одноразовые ссылки.
- **Claude Code** — скрипты бэкапа `~/.claude` и CLAUDE.md из всех репо, с автозапуском по cron.
- **Промпт для Claude Code** — заливает все локальные проекты в приватные репо с CONTEXT.md.
- **Еженедельная задача** в Scheduled — автообновление по пятницам в 18:00.
- **Инструкция по восстановлению** — что делать в первый час на новом аккаунте.

## Установка

### claude.ai (веб / десктоп)
1. Скачайте `claude-autobackup.skill` из [Releases](../../releases) или соберите zip из этой папки.
2. Settings → Skills (Capabilities) → Upload skill → выберите файл.
3. Подключите коннектор **Google Drive** (Settings → Connectors).
4. Желательно: расширение **Claude in Chrome** — тогда Claude сам проверит GitHub, запустит экспорт и создаст задачу в Scheduled.

### Claude Code
```bash
git clone https://github.com/<owner>/claude-autobackup ~/.claude/skills/claude-autobackup
```

## Быстрый старт

В новом чате на claude.ai:

> Сделай полный бэкап Claude и поставь автобэкап по пятницам

Claude пройдёт шаги A1–A7 из `SKILL.md` и в конце скажет, что осталось сделать руками. Обычно это три вещи:

1. Перетащить архивы экспорта из «Загрузок» в папку Claude Backup.
2. В терминале: `cd ~/projects && claude` и вставить промпт из документа 03.
3. Поставить cron для скрипта бэкапа Claude Code (команда в документе 02).

## Восстановление

На новом аккаунте: подключить Google Drive, включить память, установить этот скилл и написать:

> Восстанови всё из папки Claude Backup

## Безопасность

- Claude не вводит пароли и коды подтверждения — это всегда делаете вы.
- Скрипты не берут `.credentials.json`; промпт для GitHub проверяет код на секреты перед коммитом и создаёт только приватные репо.
- Документ памяти содержит личные данные — не открывайте доступ к папке по ссылке.

## Структура

```
SKILL.md                      — инструкции для Claude (три режима: настройка, обновление, восстановление)
references/gotchas.md         — грабли с Drive/Docs/Sheets/экспортом и как их обходить
templates/                    — шаблоны документов 00, 01, 02, карточки и реестра
prompts/github-push.md        — промпт для Claude Code (пуш на GitHub)
prompts/scheduled-weekly.md   — промпт еженедельной задачи
scripts/backup-claude-code.*  — бэкап Claude Code для macOS/Linux и Windows
```
